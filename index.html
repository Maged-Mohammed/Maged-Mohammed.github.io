How I work

Engineering principles I apply

Clean, tested code that a team can keep building on, delivered faster with AI that I direct and review.

01

SOLID and clean architecture

Small classes with one job, clear boundaries between layers, and dependencies you can swap without rewriting the system.

02

Design patterns and OOP

Repositories, services, strategies and events where they earn their place, not everywhere.

03

Tests before merge

Unit and integration tests, offline fixtures for external APIs, and deliberate breakage checks to prove the tests catch real bugs.

04

AI-augmented workflow

I direct AI coding agents like a tech lead: written specs, project rules, phased roadmaps and approval checkpoints.

05

Review and Git discipline

Every change is reviewed, with small focused commits, a readable history and documentation that stays up to date.

06

Security by default

Secrets never in code, least-privilege tokens, and rate limits with backoff for every external system.
